# PM Check-In

Copy this file to `.pm/checkins/YYYY-MM-DD/HHMM-short-task-name.md` for each
meaningful session. Create a new file; never edit or overwrite another
agent's check-in. Keep the record factual and concise. It is not a roadmap.

## Status

## Changed

What is now materially different in the project.

## Still Open

Anything incomplete or unresolved.

## Blockers

Only real blockers. Write "None" if there are none.

## Important Discovery

Anything discovered that may affect future work. Omit if none.

## Suggested Next Step

The logical technical continuation from this agent's perspective.

## PM Attention

Anything requiring founder approval, prioritization, strategic judgment, or
coordination. Write "None" if none.
