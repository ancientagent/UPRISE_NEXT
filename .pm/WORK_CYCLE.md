# UPRISE App-Side Work Cycle

`founder direction -> owner spec -> manager packet -> specialist artifact -> implementation -> independent review -> manager disposition`

- Context Steward promotes accepted durable truth into one owner spec.
- Marketing stores campaign roadmaps, positioning, landing/media briefs, and
  measurement proposals in the manager-routed package or communications plan.
- Design turns an accepted marketing/product brief into a bounded screen package.
- Executors implement one accepted packet and produce a factual check-in.
- Review evidence is tied to exact revision/environment and returns to Manager.
- Manager alone accepts, returns, defers, rejects, supersedes, or blocks.

No chat, prototype, campaign concept, handoff, or memory becomes product or
implementation authority without its routed owner and disposition.
