# Public Launch Terminal Screen Package

Status: design-only, founder-favored visual target pending exact image approval
Package lane: `uprise-design-ui`
Durable owner spec: none yet; see the open owner-contract questions in the UX plan

## Purpose

Coordinate one bounded public prelaunch screen: the UPRISE terminal/archive that
people encounter before the separate activation, account, and Home Scene flows.
The first visible section is **Dispatches**, a curated index of team-published
community updates. It shares one public information shell with **Blog**,
**System**, and **Contact**.

This package is a design handoff, not product doctrine. It does not authorize
routes, content management, email storage, narrated-audio hosting, login,
onboarding, or the launch-day activation flow.
